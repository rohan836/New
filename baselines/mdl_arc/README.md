# Legacy Transformer Baseline

This directory contains the transformer training system that was present in the repository before the autonomous solver was introduced.

## Run

From this directory:

    python run_script.py medium

The baseline expects its own dataset/build artifacts under this directory.

## Role

This code is retained for reproducibility and comparison. It is not part of the autonomous solver.

Autonomous research code lives in the repository root under src/autonomous_arc/.
